## Uni++ EDU Studio Config: Unitree AS2 Basic

This configuration is based on `unitree_sdk2_python/example/as2` and mainly provides AS2 sport control (SportClient).

## Notes

1. Ensure the area around the robot is clear and be ready to emergency stop.
2. Recommended init sequence:
   - Start → Init AS2 Channel → Init Sport Client
3. `GetState` prints the state map for teaching/debugging.
