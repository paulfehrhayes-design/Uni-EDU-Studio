## Uni++ EDU Studio Config: Unitree R1 Basic

This configuration is based on `unitree_sdk2_python/example/r1` and provides high-level locomotion control (LocoClient).

## Notes

1. Ensure the area around the robot is clear and be ready to emergency stop.
2. Recommended init sequence:
   - Start → Init R1 Channel → Init Loco Client
3. `Start` enters locomotion mode. Follow the SDK example safety requirements.
